            Authorized apps

            How to get started

            Upgrade to a paid plan

            MCP access is included on every paid Details plan.

            Upgrade

            Pick your AI tool

            Choose your client and we'll show you exactly how to connect it.

            Add Details to Claude Code

            Run this once in a terminal to register Details for your user account.

            claude mcp add details --scope user --transport http https://api.details.so/mcp

            Open the MCP menu

            Start Claude Code, enter the command below, then choose Details.

            /mcp

            Approve the connection

            Choose Authenticate and sign in to your Details account in the browser.

            Ready to use

            Return to Claude Code and start searching Details.

            Open MCP settings

            In Cursor, open Settings → Tools & MCP and choose New MCP Server. Use global settings for every project, or project settings for one workspace.

            Add the Details server

            Paste this configuration into your mcp.json file and save it.

            { "mcpServers": { "details": { "url": "https://api.details.so/mcp" } } }

            Connect your account

            Back in Tools & MCP, find Details, choose Connect, and approve access in the browser.

            Ready to use

            Details is now available to Cursor in the scope you selected.

            Add the Details MCP server

            Run this once in a terminal to register the remote server.

            codex mcp add details --url https://api.details.so/mcp

            Start the login flow

            Run the login command to open Details authorization in your browser.

            codex mcp login details

            Approve the connection

            Sign in to Details, review the request, and choose Continue.

            Ready to use

            Return to Codex. Start a new session if it was already open during setup.

            Open MCP connections

            From the chat input, open the add menu, choose MCPs, then select Add MCP.

            Enter the server details

            Name the connection Details and paste the remote server URL.

            https://api.details.so/mcp

            Approve the connection

            Select OAuth when prompted, then sign in and approve Details access.

            Ready to use

            Details is now available from your v0 chat.

            Find your client's MCP settings

            Open the integrations or MCP area in your AI client.

            Add the server URL

            Create a remote HTTP MCP server named Details and paste this address.

            https://api.details.so/mcp

            Approve the connection

            Use OAuth when available, then sign in and approve access to Details.

            Ready to use

            The Details tools should now appear in your client.
