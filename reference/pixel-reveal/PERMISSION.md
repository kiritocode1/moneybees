# Pixel Reveal: provenance

Source: https://pixel-text-reveal.vercel.app/ (Pixel Reveal v2.0, by Yousuf).
On 2026-09-24 Aryan asked the author, who replied that the minified site code
may be used to build our own version, and that an optimised open-source
replacement will follow. `bundle/` holds the chunks as served that day. Our
implementation lives in `components/pixel-reveal/` and keeps the same props so
the official package can replace it.
